06 · Motion

动效系统

统一克制：全部在 0.15~0.3s 内完成，以"上浮 + 阴影 + 颜色翻转"三种反馈为主，不搞花哨动画。鼠标悬停下面的色块试试。

卡片上浮

产品卡 hover 上移 6px、新闻卡 5px、胶囊 3px —— 层级越高浮得越多

阴影加深

默认无影 → hover 出现大阴影，如产品卡 0 20px 48px rgba(0,0,0,.10)

描边切蓝

卡片 hover 时边框从 #E8E8E8 变为品牌蓝 —— 可交互性的统一信号

按钮颜色翻转

描边按钮 hover 时前景/背景互换；主按钮加深蓝；按下 scale(0.98)

下划线生长

导航链接 hover 时蓝色下划线从左侧 scaleX 展开（0→1，0.2s）

图片微缩放

卡片 hover 时内部图片 scale(1.05)，0.3s —— 方向统一向上放大

07 · UX Decisions

交互体验决策（从代码读出的设计意图）

1
吸顶导航 + 毛玻璃

95% 白 + backdrop-filter blur(12px)，滚动时内容透出但不干扰可读性

2
滚动锚点导航

scroll-behavior: smooth，导航直链各区块 id，单页浏览无跳变

3
无 JS 选项卡

纯 CSS radio hack 实现 Tab，零依赖、零闪烁 —— 移动端横向滑动

4
渐进增强首屏

Hero 依次尝试 AVIF → WebP → MP4 视频，同时尊重 prefers-reduced-motion

5
无障碍细节

装饰性 SVG 标 aria-hidden、交互控件带 aria-label、图片带完整 alt

6
性能优先

图片全部 loading="lazy"（首屏除外）、移动端汉堡菜单收起导航

7
常驻转化入口

右下角悬浮 WhatsApp / 邮件 / 回顶，随时触达销售 —— B2B 询盘导向

8
明确的操作层级

每区块一个主按钮 + 一个次级按钮；整卡可点（产品/新闻卡）扩大热区

一句话总结这套设计

「硬朗直角按钮 × 圆角柔和卡片 × 单一品牌蓝」 —— 用大字号 + 高字重建立信息层级，用蓝色只标记"可交互"，用统一的 hover 反馈（上浮 / 描边变蓝 / 颜色翻转）让整站手感一致。这是一套很适合 B2B 高端硬件的成熟风格：专业、克制、可信。
